# 项目结构规范

## 1. Monorepo 结构

### 包管理

- 使用 **pnpm workspace** 管理多个包
- 包类型:
  - `apps/*` - 应用包
  - `packages/*` - 共享包

### 依赖管理

```
package.json
├── dependencies      # 运行时依赖
├── devDependencies   # 开发时依赖
└── peerDependencies  # 对等依赖
```

## 2. 应用层结构 (apps/)

### 主应用 (sc-cloud-basic)

apps/sc-cloud-basic/

## 4. API 设计规范

### 目录结构

```
src/api/
├── [模块名]/
│   ├── index.ts                  # API 导出
│   ├── index.interface.ts        # 类型定义
│   └── [功能名].ts               # 具体 API 实现 (可选)
└── index.ts                      # 统一导出
```

### API 文件规范

```typescript
// index.ts
import { api } from '@repo/utils'

export const getXXX = (params?: Params) => api.get('/path', { params })
export const createXXX = (data: Data) => api.post('/path', data)
export const updateXXX = (data: Data) => api.put('/path', data)
export const deleteXXX = (params: Params) => api.delete('/path', { params })

// index.interface.ts
export interface Params {
    id?: string
}

export interface Data {
    // 数据结构
}
```

## 5. 组件开发规范

### 组件目录结构

```
packages/react-components/[组件名]/
├── index.tsx             # 组件实现
├── index.ts              # 导出
└── [组件名].module.scss  # 样式文件
```

### 组件编写规范

- 使用 TypeScript
- 使用 CSS Modules (`.module.scss`)
- 使用 Ant Design 组件
- 遵循单一职责原则

## 6. 样式规范

### 样式文件

- 页面样式: `[页面名].module.scss`
- 全局样式: 在 `index.scss` 中定义
- 组件样式: `[组件名].module.scss`

### 样式命名

- 使用 BEM 命名规范
- 避免使用全局样式
- 使用 CSS Modules 实现样式隔离

## 7. 路由规范

### 路由文件

```
src/router/
├── async-component.tsx   # 异步组件
├── auth.tsx              # 路由守卫
└── index.tsx             # 路由定义
```

### 路由定义

```typescript
const routers = createBrowserRouter([
    {
        path: '/',
        handle: {
            isAuth: true
        },
        element: <Auth>{asyncComponent(() => import('@/pages/xxx'))}</Auth>,
    },
])
```

## 8. 类型定义规范

### 类型文件位置

- API 类型: `src/api/[模块]/index.interface.ts`
- 全局类型: `types/*.d.ts`

### 类型命名

- 接口: `PascalCase`
- 类型: `PascalCase`
- 枚举: `PascalCase`
