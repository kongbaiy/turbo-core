# 技术栈与架构

注意： 不要改变或新增技术架构栈及配置，保持一致。

## 1. 技术栈概览

### 核心框架

- **React 19.2.6** - 前端框架
- **TypeScript 5.9.2** - 类型系统
- **React Router DOM 7.15.1** - 路由管理

### UI 框架

- **Ant Design 6.4.3** - 基础组件库
- **Pro Components 3.0.0-beta.1** - 企业级组件
- **自定义主题 (@repo/antd-theme)** - 主题定制

### 构建工具

- **Vite 8.0.13** - 构建工具
- **TurboRepo 2.9.14** - Monorepo 管理
- **pnpm 9.0.5** - 包管理

### 微前端

- **Qiankun 2.10.16** - 基于 single-spa 的微前端方案

### 代码质量

- **ESLint 9.39.1** - 代码检查
- **Stylelint 17.11.1** - 样式检查
- **Prettier 3.8.3** - 代码格式化
- **Husky 9.1.7** - Git hooks 管理

### 网络请求

- **Axios 1.16.1** - HTTP 客户端
- **自定义拦截器** - 统一请求/响应处理

### 样式方案

- **CSS Modules** - 组件级样式隔离
- **SCSS** - 预处理器
- **UnoCSS** - 原子化 CSS
- **Ant Design CSSinJS** - 样式扫描和主题定制

## 2. 项目架构

### 架构模式

```
Monorepo + 微前端架构
├── 主应用 (sc-cloud-basic) - 负责微应用注册和启动
├── 子应用 (sc-cloud-platform) - 功能模块
└── 共享包 (packages) - 通用能力复用
```

### 目录结构

```
sc-cloud-core/
├── apps/                      # 应用层
│   ├── sc-cloud-basic/       # 主应用 (端口 3001)
│   └── sc-cloud-platform/    # 子应用 (端口 3002)
└── packages/                  # 共享包层
    ├── antd-theme/           # 主题配置
    ├── config/               # 配置包
    │   ├── eslint/          # ESLint 配置
    │   ├── stylelint/       # Stylelint 配置
    │   ├── typescript/      # TypeScript 配置
    │   └── vite/            # Vite 配置
    ├── react-components/     # 通用组件
    ├── react-hooks/          # 自定义 Hooks
    └── utils/                # 工具函数
```

## 3. 数据流与网络

### Axios 拦截器

- **请求拦截器**: 自动添加 `Authorization` 和 `sessionId` 头
- **响应拦截器**:
  - 处理 token 失效 (40101 错误码)
  - 统一错误提示
  - 支持默认响应配置

### 自定义 Hooks

- `useRequest` - 基于 react-use 的数据请求 Hook
- `useBoolean` - 布尔值状态管理
- `useQuery` - 获取 URL 查询参数
- `useClientRect` - 获取元素尺寸和位置

## 4. 开发规范

### Git Hooks

- `pre-commit`: lint-staged 检查
- `commit-msg`: commitlint 检查

### 代码检查

- TypeScript 严格类型检查
- ESLint + Prettier 统一代码风格
- Stylelint 规范样式编写

### 提交规范

- Commitlint 约束提交信息
- 支持 Angular 提交规范

## 5. 微前端实现

### 主应用 (sc-cloud-basic)

- 端口: 3001
- 负责注册和启动微应用
- 配置沙箱隔离环境

### 子应用 (sc-cloud-platform)

- 端口: 3002
- 使用 `vite-plugin-qiankun` 插件
- 开发模式启用 special dev mode
- 配置 CORS 和跨域头

### 通信方式

- Qiankun props 传递
- 共享全局状态 (通过 utils)

## 6. 安全机制

- Token 自动附加
- 401 错误自动跳转登录
- Session 管理
- 存储加密 (SHA256)
- XSS 防护 (React 默认转义)
