# 租户管理需求

## 1. 需求概述

### 功能定位
租户管理是平台端的基础功能，负责管理集团租户和企业租户的创建与维护。

### 涉及人员
- ROOT 账号
- 平台运营人员
- 实施人员

### 主要功能
- 租户创建
- 租户信息维护
- 租户状态管理
- 租户管理员初始化

## 2. 功能模块

### 2.1 租户类型

#### 集团租户
- 可以创建企业子租户
- 需要设置企业数量限制
- 作为集团总部

#### 企业租户
- 不能创建子租户
- 属于集团租户的下级单位
- 有独立的组织和人员管理

### 2.2 租户管理功能

#### 新增租户
1. 选择租户类型
2. 填写租户信息
3. 设置企业数量限制（集团租户）
4. 设置租户编码
5. 配置管理员账号
6. 保存并初始化

#### 编辑租户
1. 查看租户基本信息
2. 修改租户名称
3. 修改公司信息
4. 修改企业数量限制（集团租户）
5. 修改状态

#### 停用租户
1. 确认租户状态
2. 确认是否有未处理的业务
3. 停用租户

### 2.3 账号管理

#### 账号规则
- 格式: `账号@租户编码`
- 示例: `admin@ad123321`
- ROOT/SYSTEM 账号除外

#### 账号绑定
- 管理员账号必须符合账号规则
- 同一手机号只能绑定一个有效租户成员
- 管理员账号用于初始化租户

## 3. 业务规则

### 租户层级关系
```
集团租户
├── 企业租户 1
├── 企业租户 2
└── 企业租户 3
```

### 企业数量限制
- 集团租户可以设置最大企业数量
- 企业租户不能再创建子租户
- 企业数量不能超过限制

### 状态管理
- 启用: 租户可正常使用
- 停用: 租户不可访问

### 数据归属
- 租户数据属于平台端
- 不归属任何企业或商户

## 4. API 接口

### 获取租户列表
```
GET /admin/basic/tenants
```

### 获取租户详情
```
GET /admin/basic/tenant/detail
```

### 创建租户
```
POST /admin/basic/tenant
```

### 更新租户
```
PUT /admin/basic/tenant
```

### 删除租户
```
DELETE /admin/basic/tenant
```

## 6. 权限控制

### 访问权限
- ROOT 账号: 全部权限
- 平台运营人员: 可查看、新增、编辑、删除
- 实施人员: 可查看、新增、编辑

### 操作权限
- 查看列表: 需要租户管理权限
- 新增租户: 需要租户管理权限
- 编辑租户: 需要租户管理权限
- 删除租户: 需要租户管理权限

## 7. 数据初始化

### 预置租户
- ROOT 租户: 系统预置
- 企业租户: 手动创建

### 初始化配置
- 租户编码: 自动生成或手动设置
- 管理员账号: 手动配置
- 企业数量: 集团租户需要设置
