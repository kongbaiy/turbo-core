# 安全治理需求

## 1. 需求概述

### 功能定位
安全治理负责系统的安全审计和敏感访问监控，确保系统符合等保要求。

### 涉及人员
- ROOT 账号
- 平台运营人员
- 安全管理员

### 主要功能
- 操作审计
- 敏感访问监控
- 登录安全策略配置
- 安全策略管理

## 2. 功能模块

### 2.1 操作审计

#### 审计日志
记录关键操作，辅助安全审计和问题追溯。

**显示字段**
| 字段 | 说明 | 必填 | 数据类型 |
|------|------|------|----------|
| 操作人 | 操作的用户 | 是 | String |
| 租户 | 操作的租户 | 是 | String |
| 操作类型 | 操作的类型 | 是 | Enum |
| 操作内容 | 操作的具体内容 | 是 | String |
| 操作时间 | 操作的时间 | 是 | DateTime |
| 操作结果 | 操作的结果 | 是 | Enum(成功/失败) |

#### 操作类型
- 登录: 用户登录
- 登出: 用户登出
- 新增: 新增数据
- 编辑: 编辑数据
- 删除: 删除数据
- 启用: 启用资源
- 停用: 停用资源

#### 查询筛选
- 按操作人筛选
- 按租户筛选
- 按操作类型筛选
- 按时间范围筛选

### 2.2 敏感访问监控

#### 敏感字段
- 手机号: 敏感字段
- 身份证号: 高敏感字段
- 薪资: 专项敏感字段
- 银行账号: 高敏感字段

#### 敏感访问记录
记录敏感字段的明文访问。

**显示字段**
| 字段 | 说明 | 必填 | 数据类型 |
|------|------|------|----------|
| 访问人 | 访问的用户 | 是 | String |
| 租户 | 访问的租户 | 是 | String |
| 字段名称 | 访问的字段 | 是 | String |
| 访问时间 | 访问的时间 | 是 | DateTime |
| 访问结果 | 访问的结果 | 是 | Enum(成功/失败) |

#### 筛选条件
- 按访问人筛选
- 按租户筛选
- 按字段筛选
- 按时间范围筛选

### 2.3 登录安全策略

#### 策略配置
- 账号有效期: 设置账号的有效期
- 密码有效期: 设置密码的有效期
- 失败锁定: 连续失败次数限制
- 无操作退出: 30 分钟无操作自动退出

#### 策略开关
- 关闭: 本地开发和普通演示环境
- 开启: 执行等保登录安全策略

## 3. 业务规则

### 审计日志规则
- 关键操作必须记录
- 审计日志不可删除
- 审计日志长期保存

### 敏感访问规则
- 敏感字段访问必须记录
- 敏感访问需要授权
- 敏感访问可追溯

### 登录安全规则
- 等保策略开启后必须执行
- 弱密码检测
- 过期密码强制修改
- 连续失败锁定
- 无操作自动退出

## 4. API 接口

### 获取操作审计列表
```
GET /admin/security/audit/logs
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| operator | String | 操作人 |
| tenantId | String | 租户 ID |
| operationType | String | 操作类型 |
| startTime | String | 开始时间 |
| endTime | String | 结束时间 |

### 获取敏感访问记录
```
GET /admin/security/sensitive/access/logs
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| accessor | String | 访问人 |
| tenantId | String | 租户 ID |
| fieldName | String | 字段名称 |
| startTime | String | 开始时间 |
| endTime | String | 结束时间 |

## 6. 权限控制

### 访问权限
- ROOT 账号: 全部权限
- 平台运营人员: 可查看
- 安全管理员: 可查看、配置策略

### 操作权限
- 查看操作审计: 需要安全审计权限
- 查看敏感访问: 需要安全审计权限
- 配置安全策略: 需要安全配置权限

## 7. 数据初始化

### 预置策略
- 默认登录安全策略
- 默认审计规则
- 默认敏感字段列表

### 初始化配置
- 策略状态: 关闭（开发环境）
- 审计规则: 预置
- 敏感字段: 预置

## 8. 排查建议

### 操作审计排查
1. 按操作人、租户、操作类型、时间范围筛选
2. 查看操作详情
3. 分析操作行为

### 敏感访问排查
1. 按访问人、租户、字段、时间范围筛选
2. 查看访问详情
3. 结合权限中心检查角色和列级策略
4. 出现误访问时及时处理
