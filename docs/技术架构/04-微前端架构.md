# 微前端架构

## 1. 架构概述

### 架构模式

```
主应用 (sc-cloud-basic) + 子应用 (sc-cloud-platform)
├── 主应用负责:
│   ├── 微应用注册
│   ├── 路由管理
│   └── 应用生命周期管理
└── 子应用负责:
    ├── 功能模块实现
    ├── 自行构建部署
    └── 通过 qiankun 注册到主应用
```

### 技术方案

- **框架**: Qiankun 2.10.16 (基于 single-spa)
- **构建工具**: Vite 8.0.13
- **开发模式**: Special Dev Mode

## 2. 主应用配置

### 应用注册

```typescript
import { registerMicroApps, start } from 'qiankun'

const microList = [
    {
        name: 'sc-cloud-platform',
        entry: 'http://localhost:3002/__qiankun_entry.html',
        container: '#sc-cloud-platform',
        activeRule: '/platform',
    },
]

registerMicroApps(microList)

start({
    sandbox: {
        experimentalStyleIsolation: true,
    },
})
```

### 沙箱配置

- `experimentalStyleIsolation`: 开启严格的样式隔离
- 防止样式冲突

### 开发模式修复

```typescript
function qiankunDevHtmlFix(): Plugin {
    return {
        name: 'qiankun-dev-html-fix',
        transformIndexHtml: {
            order: 'post',
            handler(html) {
                return html.replace(
                    /<script\s+type="module">[\s\S]*?@react-refresh[\s\S]*?<\/script>\s*/gi,
                    '',
                )
            },
        },
    }
}
```

## 3. 子应用配置

### Vite 配置

```typescript
import defineConfig from '@repo/vite-config'

export default defineConfig({
    qiankun: (set) => {
        return set('sc-cloud-platform', { useDevMode: true })
    },

    plugins: [qiankunDevHtmlFix()],

    envDirAuto: true,

    server: {
        port: 3002,
        cors: true,
        origin: 'http://localhost:3002',
        headers: {
            'Access-Control-Allow-Origin': '*',
        },
        hmr: false
    }
})
```

### 入口文件

```typescript
import { renderWithQiankun, qiankunWindow } from 'vite-plugin-qiankun/dist/helper'

let root: Root | null = null

function render(props: { container?: HTMLElement } = {}) {
    const mountElement = props.container?.querySelector('#root') ?? document.getElementById('root')

    if (!mountElement) return

    root = ReactDOM.createRoot(mountElement)
    root.render(<App />)
}

renderWithQiankun({
    bootstrap() {},
    mount(props) {
        render(props)
    },
    unmount() {
        root?.unmount()
        root = null
    },
    update() {},
})

if (!qiankunWindow.__POWERED_BY_QIANKUN__) {
    render()
}
```

## 4. 资源加载

### 资源路径

- 使用相对路径或 CDN
- 避免硬编码绝对路径

### 共享依赖

- 主应用和子应用共享 React、Ant Design 等依赖
- 使用 pnpm workspace 管理

## 5. 应用通信

### Props 传递

```typescript
// 主应用
{
    name: 'sc-cloud-platform',
    entry: '...',
    container: '#sc-cloud-platform',
    props: {
        user: userInfo,
        navigate: navigateFn,
    },
}

// 子应用
const { user, navigate } = props
```

### 全局状态

- 使用 `@repo/utils` 中的工具函数
- 通过 localStorage 或 sessionStorage 共享

## 6. 开发规范

### 端口分配

- 主应用: 3001
- 子应用: 3002

### CORS 配置

- 开启 CORS
- 设置允许的源
- 添加必要的请求头

### 路由配置

- 子应用路由需要添加前缀
- 避免与主应用路由冲突

## 7. 部署规范

### 构建配置

```bash
pnpm run build
```

### 静态资源

- 构建产物上传到 CDN
- 配置正确的资源路径

### 版本管理

- 每个子应用独立版本管理
- 主应用协调版本
