# 应用管理需求

## 1. 需求概述

### 功能定位
应用管理负责平台应用的维护，区分基础平台、企业基础、人事、业财融合、流程、商家运营等应用。

### 涉及人员
- ROOT 账号
- 平台运营人员
- 实施人员

### 主要功能
- 应用创建
- 应用维护
- 应用状态管理
- 应用归属平台管理

## 2. 功能模块

### 2.1 应用类型

#### 基础平台
- 租户管理
- 应用管理
- 资源管理
- 基础配置
- 权限管理

#### 企业基础
- 企业组织人员
- 企业权限
- 企业基础配置

#### 人事业务系统
- 人事业务

#### 业财融合系统
- 合同管理

- 费用报销
- 业财融合

#### 流程系统
- 表单设计

### 2.2 应用管理功能

#### 应用列表
展示所有应用的基本信息。

**显示字段**
| 字段 | 说明 | 必填 | 数据类型 |
|------|------|------|----------|
| 应用名称 | 应用的显示名称 | 是 | String |
| 应用编码 | 应用的唯一标识 | 是 | String |
| 所属平台 | 应用归属的平台 | 是 | Enum |
| 状态 | 应用是否启用 | 是 | Enum(启用/停用) |
| 创建时间 | 应用创建时间 | 否 | DateTime |

#### 新增应用
1. 选择所属平台
2. 填写应用信息
3. 设置应用编码
4. 配置应用状态
5. 保存应用

#### 编辑应用
1. 查看应用基本信息
2. 修改应用名称
3. 修改应用编码（不可编辑）
4. 修改所属平台
5. 修改应用状态

#### 删除应用
1. 确认应用状态
2. 确认是否有依赖的资源
3. 删除应用

## 3. 业务规则

### 应用编码规则
- 全局唯一
- 不可重复
- 采用大写字母+下划线命名

### 平台归属规则
- 平台端应用: 归属平台端
- 企业端应用: 归属企业端
- 商户端应用: 归属商户端

### 状态管理
- 启用: 应用可正常使用
- 停用: 应用不可访问

### 数据归属
- 应用数据属于平台端
- 不归属任何租户

## 4. API 接口

### 获取应用列表
```
GET /admin/basic/apps
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | String | 关键字搜索 |
| status | String | 状态筛选 |

### 创建应用
```
POST /admin/basic/app
```

**请求体**
```json
{
    "name": "string",
    "code": "string",
    "platformCode": "string",
    "status": 1
}
```

### 更新应用
```
PUT /admin/basic/app
```

### 删除应用
```
DELETE /admin/basic/app
```

## 6. 权限控制

### 访问权限
- ROOT 账号: 全部权限
- 平台运营人员: 可查看、新增、编辑、删除
- 实施人员: 可查看、新增、编辑

### 操作权限
- 查看列表: 需要应用管理权限
- 新增应用: 需要应用管理权限
- 编辑应用: 需要应用管理权限
- 删除应用: 需要应用管理权限

## 7. 错误处理

### 应用编码错误
- 应用编码不能为空
- 应用编码已存在

### 平台归属错误
- 平台不存在
- 平台编码错误

### 删除错误
- 应用有依赖的资源
- 应用有依赖的角色

## 8. 数据初始化

### 预置应用
系统启动时自动创建以下预置应用:
- 基础平台
- 企业基础
- 人事业务系统
- 业财融合系统
- 流程系统
- 商家运营管理系统

### 初始化配置
- 应用编码: 预置
- 应用名称: 预置
- 所属平台: 预置
- 状态: 启用
