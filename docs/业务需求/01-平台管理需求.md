# 平台管理需求

## 1. 需求概述

### 功能定位
平台管理是系统的基础管理模块，负责全局基础能力的配置和管理。

### 涉及人员
- ROOT 账号
- 平台运营人员
- 实施人员
- 安全管理员

### 主要功能
- 平台信息管理
- 平台状态维护
- 平台入口配置
- 平台登录方式管理

## 2. 功能模块

### 2.1 平台列表

#### 功能描述
展示所有平台的基本信息和状态。

#### 显示字段
| 字段 | 说明 | 必填 | 数据类型 |
|------|------|------|----------|
| 平台名称 | 平台的显示名称 | 是 | String |
| 平台编码 | 平台的唯一标识 | 是 | String |
| 入口地址 | 平台的访问地址 | 是 | String |
| 登录方式 | 平台支持的登录方式 | 是 | String |
| 状态 | 平台是否启用 | 是 | Enum(启用/停用) |
| 创建时间 | 平台创建时间 | 否 | DateTime |

#### 操作功能
- 新增平台
- 编辑平台
- 删除平台

### 2.2 新增平台

#### 表单字段
| 字段 | 说明 | 必填 | 校验规则 |
|------|------|------|----------|
| 平台名称 | 平台的显示名称 | 是 | 不能为空，长度限制 |
| 平台编码 | 平台的唯一标识 | 是 | 不能为空，全局唯一 |
| 入口地址 | 平台的访问地址 | 是 | 不能为空，URL 格式 |
| 登录方式 | 平台支持的登录方式 | 是 | 必须选择 |
| 状态 | 平台是否启用 | 是 | 默认启用 |

#### 登录方式选项
- 账号密码 (password)
- 手机验证码 (sms)

#### 状态选项
- 启用
- 停用

#### 操作流程
1. 点击"新增平台"按钮
2. 填写表单信息
3. 点击"确认"保存
4. 返回平台列表

### 2.3 编辑平台

#### 可编辑字段
- 平台名称
- 平台编码 (不可编辑)
- 入口地址
- 登录方式
- 状态

#### 操作流程
1. 在平台列表中点击"编辑"按钮
2. 弹窗自动填充当前平台信息
3. 修改需要更新的字段
4. 点击"确认"保存
5. 返回平台列表刷新数据

### 2.4 删除平台

#### 删除确认
- 显示平台名称
- 确认删除提示

#### 删除条件
- 确认是否要删除该平台
- 确认是否有依赖关系

#### 操作流程
1. 在平台列表中点击"删除"按钮
2. 显示确认弹窗
3. 点击"确认"删除
4. 删除成功后刷新列表

## 3. 业务规则

### 平台编码规则
- 全局唯一
- 不可重复
- 采用大写字母+下划线命名

### 典型平台编码
| 平台编码 | 平台名称 | 典型用途 |
|---------|---------|---------|
| PLATFORM_PC | 平台端 PC | 平台运营和实施管理 |
| ENTERPRISE_PC | 企业端 PC | 企业管理员和业务人员使用 |
| ENTERPRISE_H5 | 企业端 H5 | 企业移动办公 |
| MERCHANT_PC | 商家端 PC | 商家运营后台 |
| MERCHANT_MINIAPP | 商家端小程序 | 商家移动经营 |
| CONSUMER_MINIAPP | C 端小程序 | 消费者入口 |

### 状态管理
- 启用: 平台可正常使用
- 停用: 平台不可访问

### 数据归属
- 平台数据属于平台端
- 不归属任何租户

## 4. API 接口

### 获取平台列表
```
GET /admin/basic/platforms
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | String | 关键字搜索 |
| status | String | 状态筛选 |

**响应格式**
```json
{
    "code": 200,
    "message": "成功",
    "data": [
        {
            "id": "string",
            "name": "string",
            "code": "string",
            "entryUrl": "string",
            "loginType": "string",
            "status": 1,
            "createdAt": "string",
            "updatedAt": "string"
        }
    ]
}
```

### 获取平台详情
```
GET /admin/basic/platform/detail
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| id | String | 平台 ID |

### 创建平台
```
POST /admin/basic/platform
```

**请求体**
```json
{
    "name": "string",
    "code": "string",
    "entryUrl": "string",
    "loginType": "string",
    "status": 1
}
```

### 更新平台
```
PUT /admin/basic/platform
```

**请求体**
```json
{
    "id": "string",
    "name": "string",
    "code": "string",
    "entryUrl": "string",
    "loginType": "string",
    "status": 1
}
```

### 删除平台
```
DELETE /admin/basic/platform
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| id | String | 平台 ID |

## 5. 页面实现

### 页面路径
```
平台端 -> 平台管理 -> 平台管理
```

### 页面组件
```
apps/sc-cloud-platform/src/pages/platform-manage/
├── index.tsx              # 主页面
├── index.module.scss      # 样式文件
└── dialog/                # 弹窗组件
    └── form.tsx           # 表单组件
```

### 表格组件
- 使用 ProTable 展示平台列表
- 支持分页
- 支持列宽调整
- 支持内容溢出显示

### 表单组件
- 使用 ProForm 实现表单
- 支持字段校验
- 支持提交和取消

### 弹窗组件
- 使用 Modal 实现弹窗
- 支持确认和取消
- 支持自定义宽度

## 6. 权限控制

### 访问权限
- ROOT 账号: 全部权限
- 平台运营人员: 可查看、新增、编辑、删除
- 实施人员: 可查看、新增、编辑
- 安全管理员: 可查看

### 操作权限
- 查看列表: 需要平台管理权限
- 新增平台: 需要平台管理权限
- 编辑平台: 需要平台管理权限
- 删除平台: 需要平台管理权限

## 7. 错误处理

### 表单校验错误
- 平台名称不能为空
- 平台编码不能为空
- 入口地址格式不正确
- 登录方式必须选择

### 网络错误
- 网络不可用
- 请求超时
- 服务器错误

### 业务错误
- 平台编码已存在
- 删除的平台有依赖关系
- 权限不足

## 8. 数据初始化

### 预置平台
系统启动时自动创建以下预置平台:
- PLATFORM_PC
- ENTERPRISE_PC
- ENTERPRISE_H5
- MERCHANT_PC
- MERCHANT_MINIAPP
- CONSUMER_MINIAPP

### 初始化配置
- 平台编码: 预置
- 平台名称: 预置
- 入口地址: 可配置
- 登录方式: 默认账号密码
- 状态: 启用
