# 代码规范

## 1. 代码风格

### 基本规范

- 使用 **TypeScript** 严格类型检查
- 使用 **ESLint** + **Prettier** 统一代码风格
- 使用 **Stylelint** 规范样式编写
- 使用 **TypeScript** 类型定义
- 未使用变量、函数、类、类型、接口等必须删除
- 未使用的导入语句必须删除
- 代码尽量符合原子化、 低耦合、高内聚、可维护、可扩展的规范。
- 单页面代码不要过长，模块不要都集中在一个文件中，尽量拆分，根据单一职责原则，每个模块应该有一个独立的文件

### 文件命名

- 组件文件: `PascalCase.tsx`
- 样式文件: `PascalCase.module.scss`
- API 文件: `camelCase.ts`
- 类型定义: `PascalCase.interface.ts`

### 代码格式

- 使用单引号 `'`
- 不使用分号 `;`
- Tab 宽度: 4
- JSX 单引号

## 2. React 组件规范

### 函数组件

```typescript
import React from 'react'

interface Props {
    name: string
    age?: number
}

const MyComponent: React.FC<Props> = ({ name, age = 18 }) => {
    return <div>{name} - {age}</div>
}

export default MyComponent
```

### 组件命名

- 使用 `PascalCase` 命名
- 文件名与组件名一致
- 使用 `React.FC` 类型定义

### Props 定义

- 使用接口定义 Props
- 可选属性使用 `?`
- 提供默认值

### State 管理

```typescript
import { useState, useCallback } from 'react'

const MyComponent = () => {
    const [count, setCount] = useState(0)

    const handleClick = useCallback(() => {
        setCount((prev) => prev + 1)
    }, [])

    return <button onClick={handleClick}>{count}</button>
}
```

## 3. API 调用规范

### 使用 useRequest Hook

```typescript
import { useRequest } from '@repo/react-hooks'

const { data, loading, error } = useRequest<DataType>(
    useCallback(() => getXXX(params), [params]),
)
```

### API 文件结构

```typescript
// src/api/[模块]/index.ts
import { api } from '@repo/utils'

export const getXXX = (params?: Params) => api.get('/path', { params })
export const createXXX = (data: Data) => api.post('/path', data)
```

### 错误处理

```typescript
const { data, loading, error } = useRequest<DataType>(
    useCallback(() => getXXX(), []),
    {
        onError: (error) => {
            console.error(error)
        },
    },
)
```

## 5. 路由规范

### 路由定义

```typescript
import { createBrowserRouter } from 'react-router-dom'
import { asyncComponent } from './async-component'
import Auth from './auth'

const routers = createBrowserRouter([
    {
        path: '/',
        handle: {
            isAuth: true
        },
        element: <Auth>{asyncComponent(() => import('@/pages/xxx'))}</Auth>,
    },
])
```

### 异步组件

```typescript
export const asyncComponent = (
    callback: () => Promise<{
        default: React.ComponentType<any>
    }>,
) => {
    const Component = React.lazy(callback)

    return (
        <React.Suspense fallback={<Loading />}>
            <Component />
        </React.Suspense>
    )
}
```

### 路由守卫

```typescript
const Auth = (props: { children: React.ReactElement }) => {
    const accessToken = getAccessToken()

    if (!Reflect.ownKeys(accessToken)?.length) {
        return <Navigate to="/login" />
    }
    return <>{props.children}</>
}
```

## 6. 类型定义规范

### 接口定义

```typescript
export interface User {
    id: string
    name: string
    email?: string
    role: UserRole
}

export type UserRole = 'admin' | 'user' | 'guest'
```

### API 类型定义

```typescript
// 接口参数
export interface GetUsersParams {
    keyword?: string
    status?: string
}

// 响应数据
export interface User {
    id: string
    name: string
}

// 创建数据
export interface CreateUser {
    name: string
    email: string
}
```

### 变量/函数

```typescript
const userName = '张三'
const getUserInfo = () => {}
```

### 常量

```typescript
const API_BASE_URL = 'https://api.example.com'
```

### CSS 类名



## 9. Git 提交规范

### 提交信息格式

```
<type>: <description>

[可选] body
[可选] footer
```

### Type 类型

- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档变更
- `style`: 代码格式变更
- `refactor`: 重构
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建过程或辅助工具变动

### 示例

```
feat: 添加平台管理页面
fix: 修复登录页面样式问题
docs: 更新技术架构文档
```

## 10. 预提交检查

### lint-staged 配置

```json
{
    "*.{vue,js,jsx}": "eslint --fix --max-warnings 0 --no-warn-ignored",
    "*.{json,md}": "eslint --fix --max-warnings 0 --no-warn-ignored",
    "*.{css,scss}": "stylelint --fix",
    "*.{ts,tsx}": "bash -c 'pnpm exec tsc --noEmit -p tsconfig.json'"
}
```

### Husky 钩子

```json
{
    "hooks": {
        "pre-commit": "lint-staged",
        "commit-msg": "commitlint -E HUSKY_GIT_PARAMS"
    }
}
```
