# 账号管理需求

## 1. 需求概述

### 功能定位
账号管理负责平台账号的全生命周期管理，包括账号的创建、维护、停用等操作。

### 涉及人员
- ROOT 账号
- 平台运营人员
- 实施人员
- 安全管理员

### 主要功能
- 账号创建
- 账号维护
- 账号停用
- 账号状态管理
- 等保安全策略配置

## 2. 功能模块

### 2.1 账号管理功能

#### 账号列表
展示所有企业平台账号的基本信息。

**显示字段**
| 字段 | 说明 | 必填 | 数据类型 |
|------|------|------|----------|
| 账号 | 账号名称 | 是 | String |
| 手机号 | 绑定的手机号 | 否 | String |
| 邮箱 | 邮箱地址 | 否 | String |
| 状态 | 账号状态 | 是 | Enum(启用/停用) |
| 账号有效期 | 账号有效期 | 是 | DateTime |
| 密码有效期 | 密码有效期 | 是 | DateTime |
| 锁定状态 | 账号锁定状态 | 是 | Enum(未锁定/已锁定) |

#### 新增账号
1. 选择账号类型
2. 填写账号信息
3. 绑定租户上下文
4. 设置账号有效期
5. 设置密码有效期
6. 保存账号

#### 编辑账号
1. 查看账号基本信息
2. 修改账号信息
3. 修改绑定的租户
4. 修改账号有效期
5. 修改密码有效期

#### 停用账号
1. 确认账号状态
2. 确认是否有未处理的业务
3. 停用账号

### 2.2 账号规则

#### 命名规则
- 普通租户账号: `账号@租户编码`
- ROOT/SYSTEM 账号: 不受限制

#### 绑定规则
- 手机号在 B 端账号体系内只能绑定一个有效租户成员
- 同一邮箱只能绑定一个有效账号

### 2.3 等保安全策略

#### 策略配置
- 账号有效期: 设置账号的有效期
- 密码有效期: 设置密码的有效期
- 失败锁定: 连续失败次数限制
- 无操作退出: 30 分钟无操作自动退出

#### 策略开关
- 关闭: 本地开发和普通演示环境
- 开启: 执行等保登录安全策略

## 3. 业务规则

### 账号有效期
- 格式: YYYY-MM-DD
- 未设置: 永久有效
- 已过期: 账号不可用

### 密码有效期
- 格式: YYYY-MM-DD
- 未设置: 永久有效
- 已过期: 登录时强制修改密码

### 失败锁定
- 连续失败次数: 默认 5 次
- 锁定时间: 默认 30 分钟
- 自动解锁: 锁定时间后自动解锁

### 无操作退出
- 默认时间: 30 分钟
- 超时自动登出
- 用户操作后重置计时器

## 4. API 接口

### 获取账号列表
```
GET /admin/basic/accounts
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | String | 关键字搜索 |
| status | String | 状态筛选 |

### 创建账号
```
POST /admin/basic/account
```

**请求体**
```json
{
    "loginAccount": "string",
    "loginPassword": "string",
    "tenantId": "string",
    "tenantCode": "string",
    "platformCode": "string",
    "clientCode": "string",
    "phone": "string",
    "email": "string",
    "accountExpireTime": "string",
    "passwordExpireTime": "string"
}
```

### 更新账号
```
PUT /admin/basic/account
```

### 停用账号
```
DELETE /admin/basic/account
```

## 6. 权限控制

### 访问权限
- ROOT 账号: 全部权限
- 平台运营人员: 可查看、新增、编辑、停用
- 实施人员: 可查看、新增、编辑
- 安全管理员: 可查看

### 操作权限
- 查看列表: 需要账号管理权限
- 新增账号: 需要账号管理权限
- 编辑账号: 需要账号管理权限
- 停用账号: 需要账号管理权限

## 7. 错误处理

### 账号命名错误
- 账号格式不正确
- 账号已存在

### 手机号绑定错误
- 手机号已绑定其他租户
- 手机号格式不正确

### 密码错误
- 弱密码检测
- 密码长度不符合要求

## 8. 数据初始化

### 预置账号
- ROOT 账号: 系统预置
- SYSTEM 账号: 系统预置

### 初始化配置
- 账号: 根据租户编码生成
- 密码: 用户自定义
- 有效期: 根据安全策略设置
