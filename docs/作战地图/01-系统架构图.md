## 4. 数据流向

### 用户登录流程
```
用户 → 登录页 → 账号密码验证 → 获取 Token → 存储 Token → 跳转首页
                             ↓
                        Token 刷新
                             ↓
                        Token 验证 → 跳转对应端
```

### 权限验证流程
```
用户请求 → 路由守卫 → Token 验证 → 权限验证 → 放行/拒绝
                              ↓
                         401 错误处理
                              ↓
                        跳转登录页
```

### 数据请求流程
```
组件 → useRequest → API 调用 → Axios 拦截器 → 后端接口
                             ↓
                        响应拦截器 → 错误处理 → 返回数据
```
