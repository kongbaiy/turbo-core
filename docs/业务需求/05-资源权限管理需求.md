# 资源权限管理需求

## 1. 需求概述

### 功能定位
资源权限管理负责维护菜单、页面、按钮、API等权限资源，是系统权限体系的基础。

### 涉及人员
- ROOT 账号
- 平台运营人员
- 实施人员
- 权限管理员

### 主要功能
- 资源创建
- 资源维护
- 角色授权
- 权限预览

## 2. 功能模块

### 2.1 资源类型

#### 菜单资源 (MENU)
- 左侧菜单或目录
- 可以包含子菜单
- 用于页面导航

#### 页面资源 (PAGE)
- 可以进入的页面
- 通常绑定菜单资源
- 是权限判断的基本单位

#### 按钮资源 (BUTTON)
- 页面按钮
- 如新增、编辑、删除
- 更细粒度的权限控制

#### API 资源 (API)
- 后端接口权限点
- 接口级别的权限控制

### 2.2 资源层级关系
```
MENU (菜单)
├── MENU (子菜单)
│   └── PAGE (页面)
│       ├── BUTTON (按钮)
│       └── API (接口)
└── PAGE (页面)
    ├── BUTTON (按钮)
    └── API (接口)
```

### 2.3 资源管理功能

#### 资源列表
展示所有资源的基本信息。

**显示字段**
| 字段 | 说明 | 必填 | 数据类型 |
|------|------|------|----------|
| 资源名称 | 资源的显示名称 | 是 | String |
| 资源编码 | 资源的唯一标识 | 是 | String |
| 资源类型 | 资源的类型 | 是 | Enum |
| 父级资源 | 资源的父级 | 否 | String |
| 状态 | 资源是否启用 | 是 | Enum |
| 创建时间 | 资源创建时间 | 否 | DateTime |

#### 新增资源
1. 选择资源类型
2. 填写资源信息
3. 设置资源编码
4. 选择父级资源（可选）
5. 配置资源状态
6. 保存资源

#### 编辑资源
1. 查看资源基本信息
2. 修改资源名称
3. 修改资源编码（不可编辑）
4. 修改父级资源
5. 修改资源状态

#### 删除资源
1. 确认资源状态
2. 确认是否有依赖的角色
3. 删除资源

### 2.4 角色授权

#### 授权资源
- 菜单授权
- 页面授权
- 按钮授权
- API 授权

#### 行列策略
- 行级策略: 控制数据范围
- 列级策略: 控制字段可见性

#### 权限预览
- 查看某个人最终能看到什么
- 多角色权限叠加计算

## 3. 业务规则

### 资源编码规则
- 全局唯一
- 不可重复
- 采用大写字母+下划线命名

### 资源依赖规则
- 被菜单、按钮、API、角色引用的资源不要随意删除
- 删除资源前需要确认依赖关系

### 授权顺序
```
配置资源 → 创建角色 → 授权资源 → 分配角色 → 权限预览验证
```

### 数据归属
- 资源数据属于平台端
- 不归属任何租户

## 4. API 接口

### 获取资源列表
```
GET /admin/basic/resources
```

**请求参数**
| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | String | 关键字搜索 |
| type | String | 资源类型 |
| status | String | 状态筛选 |

### 创建资源
```
POST /admin/basic/resource
```

**请求体**
```json
{
    "name": "string",
    "code": "string",
    "type": "MENU|PAGE|BUTTON|API",
    "parentId": "string",
    "status": 1
}
```

### 更新资源
```
PUT /admin/basic/resource
```

### 删除资源
```
DELETE /admin/basic/resource
```

### 角色授权
```
POST /admin/basic/role/authorize
```

**请求体**
```json
{
    "roleId": "string",
    "resourceIds": ["string"]
}
```

## 6. 权限控制

### 访问权限
- ROOT 账号: 全部权限
- 平台运营人员: 可查看、新增、编辑、删除
- 实施人员: 可查看、新增、编辑
- 权限管理员: 可查看、新增、编辑、授权

### 操作权限
- 查看列表: 需要资源管理权限
- 新增资源: 需要资源管理权限
- 编辑资源: 需要资源管理权限
- 删除资源: 需要资源管理权限
- 角色授权: 需要权限管理权限

## 7. 错误处理

### 资源编码错误
- 资源编码不能为空
- 资源编码已存在

### 删除错误
- 资源有依赖的角色
- 资源有依赖的菜单

### 授权错误
- 角色不存在
- 资源不存在

## 8. 数据初始化

### 预置资源
系统启动时自动创建以下预置资源:
- 基础平台相关资源
- 企业基础相关资源
- 人事业务相关资源
- 业财融合相关资源
- 流程系统相关资源
- 商家运营相关资源

### 初始化配置
- 资源编码: 预置
- 资源名称: 预置
- 资源类型: 预置
- 状态: 启用
