# 常用业务组件使用指南

本文档记录当前项目可复用的高频业务组件。组件统一从 `@repo/react-components` 导入，内部使用登录态访问企业基础服务，不需要业务页面传 `tenantId`。

## 选人 PeopleSelector

`PeopleSelector` 用于选择企业人员。组件值采用简单结构：多选返回人员对象数组，单选返回单个人员对象或 `null`。

```tsx
import { PeopleSelector } from '@repo/react-components'
import type { SelectorPersonRecord } from '@repo/react-components'

const [people, setPeople] = useState<SelectorPersonRecord[]>([])

<PeopleSelector
    multiple
    value={people}
    onChange={(value) => setPeople(value)}
    placeholder='请选择成员'
/>
```

单选：

```tsx
const [person, setPerson] = useState<SelectorPersonRecord | null>(null)

<PeopleSelector
    multiple={false}
    value={person}
    onChange={(value) => setPerson(value)}
/>
```

在 Ant Design Form 中使用：

```tsx
<Form.Item name='members' label='成员'>
    <PeopleSelector multiple />
</Form.Item>
```

常见提交映射：

```ts
const memberIds = people.map((item) => item.memberId).filter(Boolean)
const employeeIds = people.map((item) => item.employeeId).filter(Boolean)
```

人员字段说明：

- `memberId`：租户成员 ID，角色成员、组织成员等业务优先使用。
- `employeeId`：员工档案 ID。
- `userId`：用户 ID。
- `employeeName || userName`：页面展示姓名。
- `postName`、`deptFullName || deptName`：岗位和部门展示信息。

最近人员规则：

- “最近”只读取本地 `localStorage`，不会调用接口。
- 缓存 key 为 `sc-cloud:biz-selectors:recent-people`。
- 点击“确定”后，组件会把本次确认的人员写入最近人员，按人员 ID 去重，最多保留 20 人。
- 最近人员不会因为关闭浏览器会话自动清空；只有清理站点数据或后续显式清空逻辑才会删除。

## 选部门 DeptSelector

`DeptSelector` 用于选择组织部门。组件值采用简单结构：多选返回部门对象数组，单选返回单个部门对象或 `null`。

```tsx
import { DeptSelector } from '@repo/react-components'
import type { SelectorDeptRecord } from '@repo/react-components'

const [depts, setDepts] = useState<SelectorDeptRecord[]>([])

<DeptSelector
    multiple
    value={depts}
    onChange={(value) => setDepts(value)}
    placeholder='请选择部门'
/>
```

单选：

```tsx
const [dept, setDept] = useState<SelectorDeptRecord | null>(null)

<DeptSelector
    value={dept}
    onChange={(value) => setDept(value)}
/>
```

在 Ant Design Form 中使用：

```tsx
<Form.Item name='dept' label='部门'>
    <DeptSelector />
</Form.Item>
```

常见提交映射：

```ts
const deptId = dept?.deptId
const deptIds = depts.map((item) => item.deptId).filter(Boolean)
```

部门字段说明：

- `deptId`：部门 ID，提交业务关系时优先使用。
- `deptCode`：部门编码。
- `deptName`：部门名称。
- `parentId`：父级部门 ID。
- `companyId`、`companyName`：所属公司信息。
- `orgNature`、`orgStatus`：组织性质和状态。

常用属性：

```tsx
<DeptSelector
    multiple
    parentId='ROOT_DEPT_ID'
    allowSelectParent={false}
    usePermission
    placeholder='请选择末级部门'
/>
```

- `multiple`：是否多选，默认 `false`。
- `parentId`：指定部门树根节点，不传则由后端返回当前租户范围内的部门树。
- `allowSelectParent`：是否允许选择有子级的部门，默认 `true`。
- `usePermission`：是否按后端权限过滤下级部门，默认 `false`。

## 注意事项

- 两个组件都不返回旧系统的 `fieldTypeCode/isArray/value` 包装结构。
- 页面提交前按业务接口需要自行映射为 `memberId`、`employeeId`、`deptId` 等字段。
- 组件内部不主动传 `tenantId`，租户由后端从登录态解析。
- 不要在业务页面复制选择器接口封装；需要选人/选部门时直接复用本文档组件。
